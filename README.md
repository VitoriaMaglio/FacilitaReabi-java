# FacilitaReabi-java <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/java/java-original.svg" width="60" alt="Java logo">

Projeto em Java desenvolvido para Hospital das Clínicas, com objetivo de reduzir a taxa de absenteísmo em teleconsultas por meio da inclusão digital de pacientes.


<img>

##Funcionalidades
-Instruir os usuários a utilizarem as tecnologias disponíveis(teleconsultas) para facilitar o acesso à saúde.

-Tornar mais eficiente a filtragem de usuários que estão aptas à serem indicadas aos serviços on-line.

-Diminuir em 20% a taxa de absenteísmo à consultas digitais.
